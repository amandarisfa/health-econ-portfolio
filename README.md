# Health Economics Portfolio 1

**Author:** Farzuqna Risfa Amanda
**University:** Monash University, Master of Economics  
**Status:** In progress

## Project Overview
This project analyses whether socioeconomic disadvantage predicts 
avoidable hospitalisations across Australian Primary Health Network 
(PHN) regions, using data from the Australian Institute of Health 
and Welfare (AIHW) and the ABS SEIFA index.

## Research Question
Does socioeconomic disadvantage predict avoidable hospitalisations 
across Australian PHN regions?

## Data Sources
- AIHW MyHospitals — avoidable hospitalisation rates by region
- ABS SEIFA Index — socioeconomic index by area

## Tools & Methods
- R (tidyverse, ggplot2)
- OLS regression analysis
- Data visualisation

## Repository Structure
- `data/` — raw and cleaned datasets
- `scripts/` — R scripts for cleaning, analysis, visualisation
- `output/` — charts, tables, and final report
